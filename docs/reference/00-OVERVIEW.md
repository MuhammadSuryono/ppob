# 📚 Technical Reference Overview

## 1. Introduction
This directory serves as the technical encyclopedia for the PPOB platform. It contains detailed specifications for external integrations, internal service contracts, data models, and error taxonomies.

## 2. Reference Categories

### 2.1 External Provider Reference
Comprehensive technical documentation for the primary upstream provider, **Digiflazz**.
- **Topics:** Signature formulas, transaction parameters, webhook payloads, and response codes.

### 2.2 Internal Service Reference
Detailed API contracts for all microservices in the PPOB ecosystem.
- **Topics:** Request/Response schemas, endpoint catalog, and global headers.

### 2.3 Data Reference
Definitions of core data structures and sample data for development and testing.
- **Topics:** Product SKU examples, category metadata, and JSON schemas.

### 2.4 Error & Status Reference
The definitive guide to system statuses and error codes.
- **Topics:** Digiflazz RC mapping, internal error taxonomy, and user-facing message mapping.
